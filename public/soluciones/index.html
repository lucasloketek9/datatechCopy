Soluciones

Software de gestión para cada tipo de institución de salud

Cuatro líneas de producto que se adaptan a la operatoria de cada cliente y se combinan entre sí para abarcar la totalidad de las necesidades de un prestador.

Qué incluye cada solución

La tabla compara las principales funcionalidades de los cuatro sistemas. Los módulos se combinan entre sí, de modo que una institución puede sumar funciones de otra línea de producto. Las interfaces y las autorizaciones en línea se detallan en integraciones.

Todas las funcionalidades
«Incluido» indica que la funcionalidad figura en la descripción de cada sistema, y el guion indica que no figura en ella. El sistema para hospitales y sanatorios incluye también laboratorio de análisis clínicos y servicios de diagnóstico, y los módulos se pueden combinar entre sí.
