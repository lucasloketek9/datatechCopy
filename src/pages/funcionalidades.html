Funcionalidades

Funcionalidades del sistema de gestión para instituciones de salud

La facturación a obras sociales y prepagas, la liquidación de honorarios médicos, la historia clínica, los turnos y las interfaces con financiadores, equipos y contabilidad son procesos que atraviesan a toda la institución. Varias de estas funcionalidades forman parte de más de una línea de producto Datatech, y los módulos se combinan entre sí.

Modulares

El software para hospitales y sanatorios es modular y se adapta a las necesidades y posibilidades de cada cliente. El sistema de laboratorio puede combinarse con otros módulos Datatech.

Menos carga de datos

En el sistema para hospitales y sanatorios, los datos se agregan a partir de las solicitudes de prestaciones y forman la base de información de la institución.

Información de gestión

Todos los productos Datatech proveen información de gestión a partir de las estadísticas que generan.
